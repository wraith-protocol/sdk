# Wallet & Authorization Signature Domain Separation

Every off-chain authorization and wallet-signed payload generated by `@wraith-protocol/sdk` must bind unambiguously to a single chain, network, contract/program, operation, monotonic nonce, and expiration timestamp so a signature valid in one context can never authorize another.

## Inventory of SDK-Generated Signatures

## Canonical Domain Specification

### `SignatureDomain` Fields

- `chain`: `'evm' | 'stellar' | 'solana' | 'ckb'`
- `chainId`: positive `bigint` EIP-155 chain ID (required when `chain === 'evm'`; encoded as `0` in binary frames for non-EVM chains)
- `network`: canonical network string (e.g. `'eip155:2651420'`, Stellar network passphrase, `'solana:devnet'`, `'ckb:testnet'`)
- `contract`: target contract address (`0x...`, normalized lowercase), Soroban `C...` contract ID, Solana base58 program ID, or CKB `0x...` script `codeHash`
- `operation`: endpoint/intent tag (`'name.register'`, `'name.register_on_behalf'`, `'name.update'`, `'name.release'`, `'stealth.key_derivation'`)
- `nonce`: non-negative `bigint` (`u256`) tracked per `(signer, contract)`
- `expiry`: positive `bigint` Unix epoch timestamp in seconds (`nowSeconds < expiry` required)

### Binary Wire Layout (`encodeDomainAuthorizationBytes`)

Used by Stellar (`SHA-256`), Solana (`SHA-256`), and CKB (`blake2b` with `"ckb-default-hash"` personalization). Every variable-length field is prefixed with its 4-byte big-endian byte length so concatenation collisions are impossible:

```
"WRAITH-DOMAIN-SIG-V1\0" (21 bytes)
|| u32be(len(chain))     || utf8(chain)
|| u64be(chainId)
|| u32be(len(network))   || utf8(network)
|| u32be(len(contract))  || utf8(normalizedContract)
|| u32be(len(operation)) || utf8(operation)
|| u256be(nonce)         (32 bytes)
|| u64be(expiry)         (8 bytes)
|| u32be(len(payload))   || payload
```

### EVM EIP-712 Layout (`computeEvmNameAuthorizationDigest`)

```solidity
bytes32 constant DOMAIN_TYPEHASH = keccak256(
    "EIP712Domain(string name,string version,uint256 chainId,address verifyingContract,bytes32 salt)"
);
bytes32 constant NAME_AUTH_TYPEHASH = keccak256(
    "WraithNameAuthorization(bytes32 operationHash,bytes32 nameHash,bytes32 metaAddressHash,uint256 nonce,uint256 expiry)"
);
```

- `name = "Wraith Protocol"`, `version = "2"`, `salt = keccak256(bytes(network))`
- `digest = keccak256(abi.encodePacked("\x19\x01", domainSeparator, structHash))`
