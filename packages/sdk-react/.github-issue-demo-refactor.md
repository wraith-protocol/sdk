# Refactor Demo to Use @wraith-protocol/sdk-react Hooks

## Context

The `@wraith-protocol/sdk-react` package is now available with production-ready hooks for Stellar stealth address integration. The existing demo in `StellarReceive.tsx` contains 600+ lines of manual useState/useEffect glue that should be replaced with these hooks.

## Scope

Replace the manual state management in the demo with the new hooks:

- Replace key derivation logic with `useStellarStealthKeys`
- Replace announcement scanning with `useStellarAnnouncementScan`
- Replace balance fetching with `useStellarBalance`
- Remove redundant state management code
- Simplify component structure

## Expected Outcome

- Demo code reduced from 600+ lines to ~200 lines
- Cleaner, more maintainable component structure
- Better example for integrators
- Validation that the hooks work in a real application

## Benefits

- Demonstrates the DX improvement the hooks provide
- Serves as a reference implementation for integrators
- Reduces demo maintenance burden
- Validates hook API design with real-world usage

## Acceptance Criteria

- [ ] Demo uses all relevant hooks from `@wraith-protocol/sdk-react`
- [ ] All existing functionality preserved
- [ ] Code reduced by at least 60%
- [ ] No manual useState/useEffect for SDK operations
- [ ] Demo still works in React Strict Mode
